          Mathematical Foundations & Theoretical Algorithms

          Undergraduate / Graduate Statistics

          1. Probability Density Function (PDF)

          f(z) = (1 / √(2π)) · exp(-z² / 2)

          The bell-shaped curve has maximum height f(0) ≈ 0.39894 at the mean, points of inflection at z = ±1, and asymptotes to zero as |z| → ∞.

          2. Cumulative Distribution Function (CDF)

          Φ(z) = ∫_{-∞}^{z} f(t) dt = ½ [1 + erf(z / √2)]

          Calculated using high-order rational Chebyshev polynomials for double-precision accuracy (< 7.5 × 10⁻⁸ absolute error), matching all standard 4-decimal printed tables exactly.

          3. Inverse Normal Quantile Φ⁻¹(p)

          z = Φ⁻¹(p) via Peter J. Acklam's Algorithm + Halley Refinement

          Computes exact critical values (e.g. p = 0.975 → Z = 1.9600) using piecewise rational minimax polynomials followed by Halley's rational root refinement.

          4. Conventional vs. Cumulative Z-Tables

          Φ(z) = 0.5000 + P(0 < Z < z)    (for z ≥ 0)

          Conventional textbook tables display only the area between 0 and z (max 0.4999). Software cumulative tables display total area to the left (max 0.9999).
